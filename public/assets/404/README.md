# 404 memes

One reaction GIF is selected randomly when the 404 component mounts. The
selection stays put while the visitor pauses or changes motion preferences.
All files are served locally so the page does not depend on third-party requests.

| Local name | GIPHY ID | Dimensions |
| --- | --- | --- |
| `confused-travolta` | `6uGhT1O4sxpi8` | 426 × 213 |
| `homer-disappearing` | `4pMX5rJ4PYAEM` | 267 × 199 |
| `confused-math` | `WRQBXSCnEFJIuxktnw` | 504 × 322 |
| `napoleon-waiting` | `l0HlBO7eyXzSZkJri` | 400 × 275 |

For each ID, the source is `https://giphy.com/gifs/<ID>`. The animated file is
downloaded from `https://media.giphy.com/media/<ID>/giphy.gif`, and the matching
`-still.gif` from `https://media.giphy.com/media/<ID>/giphy_s.gif`.

Each still GIF has one frame and is shown when motion is reduced, Data Saver
is enabled, or the visitor pauses playback. GIFs fit inside a fixed 2:1 frame
without cropping or stretching.
